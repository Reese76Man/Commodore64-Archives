# Commodore 64 Basic (.BAS Text | .PRG Program | .D64 Disk Image)

A retro repository of a handful of the very first programs I'd written... on my first computer, the mighty Commodore 64!

Back then I went by Diceman and had a software "company" called FutureSoft.  I was between 11 and 14 when developing these before getting my very first PC compatible, a beefy 486SX25!  I didn't have access to many resources aside from the C64 manual and a handful of Compute's Gazette Magazines, so I usually learned by reverse-engineering other basic programs that I could get.  The C64 was long in the tooth by the time I got one, but would have loved to learn more ML programming.  That being said, Commodore and its Microsoft Basic set forth in motion my love of development, gaming, and computing technologies in general.
-------------------------------------------------------------------

<pre>
Coder - An early attempt at rudimentary encryption (simple flip of all 8 bits)
Cracker1 - One of a few simple cracktro-like loaders written for some of my games
Craps - A Craps dice game
CrimeBusters - A simple car chase/shooter
DiskChompers - One of the disk utilities I'd made
Draw - Basic drawing program using C64's high-res mode
FGFootball - Field Goal Football, a simple game using redefined characters
FileMaster - A SEQ file reader/writer made while learning the file types and dealing with data
FS.Comp - A simple repeating-byte compression algorithm test
FS.Letter - My own user-defined character set editor
FS.Sprite - My own sprite editor with decent features for my use
Hangman - Exactly what it sounds like... with a handful of 5 letter words within
Helecopter - A sprite/joystick testbed inspired by choplifter, probably
HomeRunDerby - A home run derby game using redefined characters, ball sprite, and sound
Jaws - Another sprite with color-change effect for a custom game loader
Monsters - A simple user-chosen monster maker using ASCII only
Plane - A slow ASCII game with intro music and game sounds and a scrollable mountain
Plane II - The sequel to Plane, but completely different in structure
SuperCopy - A file copy with a 100 byte buffer.  Pretty sure I didn't really use it
TrackSector - A custom track/sector editor for my 1541
Van Simulator - My first "simulator" of my dad's Ford Ecoline
</pre>
